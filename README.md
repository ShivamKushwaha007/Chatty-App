# 💬 MERN Chat App
A real-time chat application built with the **MERN Stack** that allows users to create accounts, log in, and send messages instantly.
The application supports real-time communication using WebSockets and provides a modern responsive UI.

---

## 🚀 Features

* 🔐 User authentication (Signup / Login / Logout)
* 💬 Real-time messaging
* 👥 One-to-one chat
* 📡 Live updates using WebSockets
* 🖼 Profile avatar support
* 🔔 Toast notifications
* 📱 Responsive UI
* ⚡ Fast frontend powered by Vite
* 🧠 Global state management using Zustand

---

## 🛠 Tech Stack

### Frontend

* React
* Tailwind CSS
* DaisyUI
* Zustand
* Axios
* React Router

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* Socket.IO
* Cloudinary (image uploads)

### Setup .env file

MONGODB_URI=...
PORT=5001
JWT_SECRET=...
CLOUDINARY_CLOUD_NAME=...
CLOUDINARY_API_KEY=...
CLOUDINARY_API_SECRET=...

NODE_ENV=development


## 🚀 Production Setup

1. Build the frontend

```bash
npm run build
```

2. Start the server

```bash
npm start
```
